Data Files

Dispatch file (daily) and mapping (Hindi / English names)

1. Dispatch file

Choose the latest Dispatch .xlsx. It is stored only in this browser (nothing is uploaded anywhere). Adding a file for a Year that is already loaded replaces it.

2. Mapping

The site reads mapping.json from your GitHub repo. To create it, choose your mapping Excel (columns GP_EN, GP_HI, PS_EN, PS_HI, DIST_EN, DIST_HI) and press Download.

How do I put mapping.json on GitHub?

Open your GitHub repo, press Add file → Upload files, drop mapping.json in the main folder (next to index.html) and press Commit changes. Wait a minute, then refresh this site.

Mapping rarely changes, so you only repeat this when new Panchayats are added. Until then you can press Use on this device to try it right away.
